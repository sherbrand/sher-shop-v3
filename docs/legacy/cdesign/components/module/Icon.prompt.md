One-line: SHER's icon glyphs — UI icons in the Lucide line style (1.5px stroke), social marks as filled Simple Icons; use anywhere a glyph is needed.

```jsx
<Icon name="bag" size={22} />
<Icon name="chevron-down" />
<Icon name="instagram" size={20} />   {/* filled brand mark */}
```

- UI names: menu, close, bag, chevron-down/-right/-left, arrow-right, minus, plus, trash, ruler.
- Brand names (filled, social only): instagram, facebook, tiktok.
- Inherits color via `currentColor`; size defaults to 20px; UI stroke defaults to 1.5px.
